# Wedding Roulette

結婚式の二次会用の、立体ヨーロピアンルーレットです。Pythonで起動し、Windowsのブラウザで操作します。Three.jsを含む必要なファイルは `public/vendor/`、効果音は `public/audio/` に同梱されており、会場でのインターネット接続は不要です。広告、ログイン、外部通信、賭けの機能はありません。

## WSLで起動

Python 3.9以降を使用します。外部Pythonパッケージは不要なので、仮想環境や `pip install` は必要ありません。Node.jsも通常の起動には不要です。

```bash
cd /home/kazu/project/nijikai
python3 serve.py
```

Windows側のChromeまたはEdgeで **http://localhost:8000** を開きます。WSLのターミナルは開いたままにしてください。終了はターミナルで `Ctrl+C` です。サーバーはローカル利用を想定していますが、WSLの全インターフェースで待ち受けます。インターネットには公開しないでください。

ポートが使用中の場合は `python3 serve.py --port 8001` とし、http://localhost:8001 を開いてください。

Windowsからlocalhostで接続できない環境では、WSLで `hostname -I` を実行し、表示されるWSLのIPアドレスを使って `http://そのIPアドレス:8000` を開きます。Windowsのファイアウォール設定やWSLのlocalhost転送設定も確認してください。HTMLを直接ダブルクリックせず、Pythonサーバー経由で開いてください。

## 会場での操作

1. Windowsの画面設定で会場スクリーンへの複製または拡張を選びます。1920×1080推奨です。
2. 拡張の場合はブラウザをスクリーン側へ移動します。
3. 右上の全画面アイコン、またはブラウザの `F11` でフルスクリーンにします。解除は `Esc`（アイコンで全画面にした場合）または `F11` です。
4. 「回す」ボタンまたはスペースキーで抽選します。約10.5秒後に番号と「赤・黒・緑」のいずれかを表示します。回転中の再操作とキーの長押しは無視します。
5. 停止後は「回す」またはスペースキーで繰り返し抽選できます。
6. 右上のスピーカーアイコンでミュート、隣のスライダーで音量を0～100%に調整できます。初期音量は50%で、設定は同じブラウザ・URLに保存されます。ミュート中の音量調整はミュートを維持します。音量0%から鳴らす場合はスライダーを上げてください。
7. 右上の「梅・竹・松」で演出を選びます。梅は通常の約10.5秒、竹は従来の特別演出で約18.5秒、松は最上位演出で約24.5秒です。設定を保存し、抽選中は変更できません。以前の特別演出ONは竹へ引き継ぎます。どの段階も抽選確率と結果の一致は同じです。

ホイールの回転音とボールの転がり音は、アニメーションと同じ進行値で再生速度・音量を変えます。停止時には回転音も終了します。ポケットに入る瞬間専用の着地音はありません。ブラウザの自動再生制限に対応するため、最初の「回す」操作で音声を準備してから抽選を開始します。タブを隠すと音とアニメーションを一時停止し、戻ると続きから再開します。音声の読み込みに失敗した場合は右上に通知し、抽選自体は無音で続行します。

効果音は独自生成したWAVファイル7種類です。通常の利用時に生成・ダウンロードする必要はありません。再生成は `python3 tools/generate_audio.py` で可能です（Python標準ライブラリのみ）。会場のスピーカーから実際に鳴らし、Windows側の音量とアプリのスライダーで調整してください。

竹の終盤では、約11.84秒・12.95秒・14.06秒に3連続の上昇音が鳴り、CHANCE表示・3段階のランプ・赤と金の照明・小さな画面の揺れが同期します。結果には立体的な金色の数字と108枚の紙吹雪を表示します。

松は5段階の上昇音、虹色の外周光、金色の発光フレームを加えます。ボール停止後、選ばれた番号を巨大な3連数字として約4.4秒表示し、重低音を重ねた4打の確定音と180枚の紙吹雪で演出します。3つの数字はすべて同じ抽選結果です。その後は通常の結果画面に戻ります。追加音はすべて全体音量とミュートに従い、結果演出中も右上で操作できます。OSの「視差効果を減らす」設定では揺れ・拡大・紙吹雪を抑えます。既存作品の画像・音声は使用していません。

ボールの転がり音と跳ねる音の相対音量は `public/audio.js` の **`BALL_SOUND_LEVEL = .8`** 一か所で調整できます（従来基準の80%）。ホイール音・全体音量には影響しません。75msの短い衝突音は、映像と共有する跳ね返り曲線の8つの接触点で鳴ります。強さに応じて音量と高さを控えめに変え、ポケットに収まる直前の接触は弱めています。追加音にもミュート・音量設定が適用されます。描画が長く止まった場合は、過去の衝突音をまとめて鳴らさず省略します。

起動直後は未抽選です。再読み込みすると結果と回数はリセットされます。省電力によるスリープやスクリーンセーバーはイベント前に無効にし、電源につないでください。Chrome / Edgeのハードウェアアクセラレーションを有効にし、事前に実機で表示確認してください。画面サイズに応じてカメラとレイアウトが調整されます。

## 抽選と描画

37番号からWeb Cryptoの乱数を使って抽選します。32ビット整数を37で割る際の余りの偏りは棄却法で除去します。過去の結果は次の抽選に影響せず、同じ番号が続く場合もあります。

並び（上から見た時計回り）は次のとおりです。

```
0, 32, 15, 19, 4, 21, 2, 25, 17, 34, 6, 27, 13, 36, 11, 30,
8, 23, 10, 5, 24, 16, 33, 1, 20, 14, 31, 9, 22, 18, 29, 7,
28, 12, 35, 3, 26
```

赤: **1, 3, 5, 7, 9, 12, 14, 16, 18, 19, 21, 23, 25, 27, 30, 32, 34, 36**。0は緑、残り18番号は黒です。

自由物理シミュレーションではなく、抽選番号のポケットに収束する制御アニメーションを使用します。ホイールと逆方向にボールが周回し、減速して内側へ落ち、小さく跳ねてポケットと一緒に停止します。選ばれたポケットは最後に手前へ来ます。結果表示の直前にボールと盤の相対角度から番号を再計算し、一致を検証します。裏に回ったボールは3Dの遮蔽に従って見えます。終了結果の番号と色は画面右側（縦画面では下側）に表示します。

## 開発・検証（通常の利用には不要）

`public/roulette.js` が並び・色・抽選・動き、`public/app.js` が3Dと操作、`public/style.css` が画面のスタイルです。起動時にコードを編集する必要はありません。

Node.js 18以降がある場合、ロジックの検証は依存パッケージなしで実行できます。

```bash
node --test tests/roulette.test.mjs tests/audio.test.mjs
```

画面検証を再実行する場合は、開発用依存関係を `npm install`、テスト用ブラウザを `npx playwright install chromium` で準備し、Pythonサーバーの起動中に `node tests/browser.mjs` を実行します。この準備時のみネット接続が必要です。既存のChromiumを使う場合は `CHROMIUM_PATH` に実行ファイルのパスを指定できます。スクリーンショットは `artifacts/` に保存します。

確認済み: 37番号の並びと色、3,700回の着地点計算、ブラウザでの17・黒／0・緑／32・赤の停止位置と結果、連打防止、スペースキー、全画面切り替え、1920×1080・1366×768・768×1024・390×844・844×390での表示。外部リクエストが発生しないことと、3D画面が描画されていることも検証しています。

Three.js 0.180.0とLucide 0.468.0を同梱しています。各ライセンスは `public/vendor/` にあります。3Dモデル・材質・画面構成は本アプリで生成した独自のもので、参考画像自体を画面に貼り付けてはいません。
